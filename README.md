# Sunny Math Racer 🏎️➕

A Pixar-inspired educational 3-lane math racing Progressive Web App (PWA) designed for kids ages 6–10. Kids solve addition problems by steering their race car into the correct answer lane to accelerate from a parked start!

## Features
- **Age-Adaptive Math:** Choose between **Under 6 Yrs** (sums under 10 with visual counting dots) or **Ages 6–10** (progressive arithmetic challenge).
- **Zero-Speed Start:** Start parked at 0 km/hr or 0 mph on the checkered starting line and accelerate +10 per correct answer.
- **Custom Garage:** Pick from 3 vehicle styles (**Race Car**, **Big Truck**, **Cool SUV**) and 3 glossy paint colors (**Lightning Red**, **Turbo Blue**, **Stealth Black**).
- **Speed & Science:** Learn the real-world meaning of speed (`km/hr` or `mph`) matched with everyday speed comparisons (Bicycles, School Buses, Express Trains).
- **Zero External Dependencies:** Built entirely with HTML5 Canvas, Tailwind CSS, and the Web Audio API (procedural engine purrs and chugs).

## How to Run Locally
1. Download or clone this repository.
2. Ensure the file is named `index.html`.
3. Double-click `index.html` to open and play directly in any web browser.

## Tech Stack
- HTML5 Canvas & Vanilla JavaScript (ES6 Classes)
- Tailwind CSS (via CDN)
- Web Audio API (Procedural Synthesizer & Engine Sound FX)
- PWA Manifest & Service Worker (Offline Ready)
